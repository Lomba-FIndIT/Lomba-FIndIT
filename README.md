## Masterskill
Masterskill merupakan sebuah platform edukasi yang berfokus pada pendidikan informal seperti menjahit, berkebun, memasak, kerajinan, dll. platform ini menyediakan berbagai course yang didalamnya terdapat video untuk pembelajaran. Selain itu platform ini juga menyediakan webinar serta informasi mengenai lamaran pekerjaan bagi para user.
